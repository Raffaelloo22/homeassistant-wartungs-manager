# Changelog

## 1.1.0

First public release of Wartungs-Manager.

- Local device directory with manual records and Home Assistant device links.
- One-off, interval, seasonal, rotating and sensor-based maintenance tasks, editable history and completion undo.
- Battery and consumable inventory with notes, usage links, stock deductions and purchase requests.
- Compact smartphone inventory, responsive navigation and balanced header spacing.
- Configurable cost currency and battery threshold helper, with compatible defaults for existing installations.
- Empty initial data, MIT license, bundled brand images and English/German setup translations.
- Marketplace/HACS package metadata and automated release validation.

The integration domain and storage name remain `ha_wartung`; existing maintenance directories from earlier private installations are retained.
